# jira_clone_infra

Infrastructure codebase for a Jira clone project.

## Repository Structure

This repo contains infrastructure as code components and automation scripts, including:

- **Docker/**: Containerization configurations
- **ansible/**: Automation and provisioning scripts
- **jenkins/**: CI/CD pipeline definitions
- **splunk/**: Logging and monitoring integrations
- **terraform/**: Cloud infrastructure provisioning

## Technologies Used

- **Jinja** (main language detected)
- **Docker**
- **Ansible**
- **Jenkins**
- **Splunk**
- **Terraform**

## Getting Started

Clone the repository:

```bash
git clone https://github.com/mrgnal/jira_clone_infra.git
cd jira_clone_infra
```

Explore each directory for specific instructions and configurations for the tool/service.
